OVERVIEW
================================================================================

3 Components:
1. Flink Job (etl-flink-1.0.0.jar) - Processes sensor data
2. ETL API (etl-api-1.0.0.jar) - REST API for configurations
3. File Producer (etl-file-producer-1.0.0.jar) - Generates sensor data

Architecture:
- Flink Job: SoftNet Cluster (clu01 master, 11 workers)
- Kafka: 4 brokers (clu02, clu03, clu04, clu06 on port 6667)
- Services: Run on clu04

Versions:
- Java 8, Flink 1.9.3, Spring Boot 2.7.18, Kafka 2.4.1

PERFORMANCE TESTING & TUNING
================================================================================

Once the system is verified working, you can tune performance parameters:

1. CHANGE DATA PRODUCTION RATE (DEFAULT: 240 msg/sec)
   ─────────────────────────────────────────────────────────────────────────

   Stop current producer:
   ps aux | grep etl-file-producer
   kill <PID>

   Start with new rate:
   cd /home/avoutas/boutasThesis
   java -jar etl-file-producer-1.0.0.jar \
       --kafka.bootstrap.servers=clu02.softnet.tuc.gr:6667,clu03.softnet.tuc.gr:6667,clu04.softnet.tuc.gr:6667,clu06.softnet.tuc.gr:6667 \
       --kafka.input.topic=etl.input.v1 \
       --producer.mode=random \
       --producer.rate.per.sec=240 &

   Produces: 240 messages/sec × 48 sensor combinations = 11,520 events/sec

   Test with higher rates: 500, 1000, 2000 msg/sec


2. CHANGE FLINK PARALLELISM (DEFAULT: -p 11)
   ─────────────────────────────────────────────────────────────────────────

   Cancel current job:
   cd /usr/local/flink
   ./bin/flink list
   ./bin/flink cancel <JOB-ID>

   Submit with different parallelism:
   ./bin/flink run -p 22 -d /home/avoutas/boutasThesis/etl-flink-1.0.0.jar \
       --kafka.bootstrap.servers clu02.softnet.tuc.gr:6667,clu03.softnet.tuc.gr:6667,clu04.softnet.tuc.gr:6667,clu06.softnet.tuc.gr:6667 \
       --kafka.config.topic etl.config.v1 \
       --kafka.input.topic etl.input.v1 \
       --kafka.output.topic etl.output.v1

   Parallelism options:
   -p 11  = 1 task per worker (baseline)
   -p 22  = 2 tasks per worker (recommended for high load)
   -p 33  = 3 tasks per worker (maximum, all slots)

   Monitor: http://clu01.softnet.tuc.gr:8081 (check backpressure, latency)


3. CHANGE WINDOWING SIZE (DEFAULT: 3 seconds)
   ─────────────────────────────────────────────────────────────────────────

   Edit source code:
   File: flink/src/main/java/com/etl/flink/EtlFlinkJob.java
   Line: ~148

   Current:
   .window(TumblingProcessingTimeWindows.of(Time.seconds(3)))

   Change to:
   .window(TumblingProcessingTimeWindows.of(Time.seconds(5)))   // 5 seconds
   .window(TumblingProcessingTimeWindows.of(Time.seconds(10)))  // 10 seconds
   .window(TumblingProcessingTimeWindows.of(Time.minutes(1)))   // 1 minute

   Then rebuild and redeploy:
   cd /home/thanasis/Documents/etl-flink-project
   mvn clean package -DskipTests
   scp flink/target/etl-flink-1.0.0.jar avoutas@clu04.softnet.tuc.gr:/home/avoutas/boutasThesis/

   Cancel old job and submit new one with updated JAR


4. SUBMIT MULTIPLE CONFIGS FOR LOAD TESTING
   ─────────────────────────────────────────────────────────────────────────

   Submit all test configs simultaneously:
   cd /home/avoutas/boutasThesis

   for config in config-*.json; do
       curl -X POST http://clu04.softnet.tuc.gr:8080/config \
           -H "Content-Type: application/json" \
