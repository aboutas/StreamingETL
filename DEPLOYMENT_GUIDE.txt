OVERVIEW
================================================================================

This project consists of 3 components:
1. Flink Job (etl-flink-1.0.0.jar) - Processes sensor data with transformations
2. ETL API Service (etl-api-1.0.0.jar) - REST API to submit configurations
3. ETL File Producer (etl-file-producer-1.0.0.jar) - Streams sensor data

ARCHITECTURE:
- Flink Job runs on SoftNet Flink Cluster (clu01 master, 11 workers)
- Kafka runs on SoftNet (4 brokers: clu02, clu03, clu04, clu06)
- Spring Boot services run on clu04

KEY CONFIGURATIONS:
- Java Version: Java 8 (compatible with cluster)
- Flink Version: 1.9.3 (compatible with cluster's Flink 1.10.0)
- Spring Boot: 2.7.18 (Java 8 compatible)
- Kafka: 2.4.1

================================================================================
STEP 3: CREATE KAFKA TOPICS
================================================================================

SSH to cluster:
ssh avoutas@clu04.softnet.tuc.gr

Navigate to Kafka:
cd /usr/hdp/current/kafka-broker

Create topics:
bin/kafka-topics.sh --create --zookeeper clu01.softnet.tuc.gr:2182 \
    --replication-factor 2 --partitions 4 --topic etl.input.v1

bin/kafka-topics.sh --create --zookeeper clu01.softnet.tuc.gr:2182 \
    --replication-factor 2 --partitions 4 --topic etl.config.v1

bin/kafka-topics.sh --create --zookeeper clu01.softnet.tuc.gr:2182 \
    --replication-factor 2 --partitions 4 --topic etl.output.v1

Verify topics:
bin/kafka-topics.sh --list --zookeeper clu01.softnet.tuc.gr:2182

================================================================================
STEP 4: DEPLOY FLINK JOB
================================================================================

4.1 SSH to cluster:
    ssh avoutas@clu04.softnet.tuc.gr

4.2 Navigate to Flink:
    cd /usr/local/flink/

4.3 Set environment variables (CRITICAL):
    export KAFKA_BOOTSTRAP_SERVERS="clu02.softnet.tuc.gr:6667,clu03.softnet.tuc.gr:6667,clu04.softnet.tuc.gr:6667,clu06.softnet.tuc.gr:6667"
    export CONFIG_TOPIC="etl.config.v1"
    export INPUT_TOPIC="etl.input.v1"
    export OUTPUT_TOPIC="etl.output.v1"

4.4 Submit Flink job:
    ./bin/flink run -p 11 -d /home/avoutas/boutasThesis/etl-flink-1.0.0.jar

    Flags:
    -p 11  = Parallelism 11 (one task per worker)
    -d     = Detached mode (runs in background)

4.5 Verify job is running:
    ./bin/flink list

    OR check Flink Dashboard: http://clu01.softnet.tuc.gr:8081

TROUBLESHOOTING:
- If you get permission errors on logs:
  export FLINK_LOG_DIR=~/flink-logs
  mkdir -p ~/flink-logs

================================================================================
STEP 5: START ETL API SERVICE
================================================================================

5.1 Navigate to project directory:
    cd /home/avoutas/boutasThesis

5.2 Start ETL API:
    java -jar etl-api-1.0.0.jar \
        --kafka.bootstrap.servers=clu02.softnet.tuc.gr:6667,clu03.softnet.tuc.gr:6667,clu04.softnet.tuc.gr:6667,clu06.softnet.tuc.gr:6667 \
        --kafka.config.topic=etl.config.v1 \
        --server.port=8080 &

5.3 Test API is running:
    curl http://clu04.softnet.tuc.gr:8080/actuator/health

    Expected response: {"status":"UP"}

5.4 View logs:
    tail -f nohup.out

================================================================================

================================================================================
IMPORTANT NOTES
================================================================================

1. JAVA VERSION: All JARs compiled with Java 8 for cluster compatibility

2. ENVIRONMENT VARIABLES: The Flink job reads configuration from environment
   variables (System.getenv). You MUST export them before submitting the job.

3. KAFKA BROKERS:
   clu02.softnet.tuc.gr:6667
   clu03.softnet.tuc.gr:6667
   clu04.softnet.tuc.gr:6667
   clu06.softnet.tuc.gr:6667

4. PARALLELISM: Set to 11 (one task per worker) for optimal performance.
   Can be adjusted: -p 22 (two per worker) or -p 33 (all slots)

5. DATA GENERATION: File Producer has two modes:
   - random: Generates realistic sensor data (all sensor types, all rooms)
   - file: Reads from JSON file

6. TESTING: Submit multiple configurations simultaneously - they run in parallel

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "Connection refused to kafka:9092"
Fix: Environment variables not set. Export them before submitting Flink job.

Issue: "Permission denied" on Flink logs
Fix: export FLINK_LOG_DIR=~/flink-logs && mkdir -p ~/flink-logs

Issue: Java version mismatch (class file version 61.0)
Fix: Rebuild project with: mvn clean package -DskipTests (already Java 8)

Issue: No output in Kafka
Fix: Check Flink job is running (./bin/flink list) and producer is sending data

Issue: API not responding
Fix: Check if port 8080 is free: netstat -tuln | grep 8080
