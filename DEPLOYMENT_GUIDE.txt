SOFTNET CLUSTER DEPLOYMENT GUIDE - ETL FLINK PROJECT
================================================================================

PROJECT OVERVIEW
----------------
This project consists of 3 components:
1. Flink Job (etl-flink-1.0.0.jar) - Processes sensor data with transformations
2. ETL API Service (etl-api-1.0.0.jar) - REST API to submit configurations
3. ETL File Producer (etl-file-producer-1.0.0.jar) - Streams sensor data from files

ARCHITECTURE: Moving away from Docker Compose to SoftNet Cluster
- Flink Job runs on SoftNet Flink Cluster (clu01 master, 11 workers)
- Kafka is already running on SoftNet (4 brokers)
- Spring Boot services run on application server (can be clu04 or your machine)

-------------------------------------------
From your local machine → SoftNet cluster:

JARs (already built in target/ directories):

STEP 3: CREATE KAFKA TOPICS ON SOFTNET CLUSTER
================================================================================

3.1 SSH to clu04:
    ssh username@clu04.softnet.tuc.gr

3.2 Navigate to Kafka:
    cd /usr/hdp/current/kafka-broker

3.3 Create input topic:
    bin/kafka-topics.sh --create --zookeeper clu01.softnet.tuc.gr:2182 \
        --replication-factor 2 --partitions 4 --topic etl.input.v1

3.4 Create config topic:
    bin/kafka-topics.sh --create --zookeeper clu01.softnet.tuc.gr:2182 \
        --replication-factor 2 --partitions 4 --topic etl.config.v1

3.5 Create output topic:
    bin/kafka-topics.sh --create --zookeeper clu01.softnet.tuc.gr:2182 \
        --replication-factor 2 --partitions 4 --topic etl.output.v1

3.6 Verify topics:
    bin/kafka-topics.sh --list --zookeeper clu01.softnet.tuc.gr:2182


================================================================================
STEP 4: DEPLOY FLINK JOB TO SOFTNET FLINK CLUSTER
================================================================================

IMPORTANT: SoftNet Flink cluster uses Flink 1.10.0, your JAR uses 1.18.1
This may cause compatibility issues. Two options:

OPTION A: Submit via Flink Dashboard (Recommended for testing)
------------------------------------------------------------
4A.1 Open Flink Dashboard: http://clu01.softnet.tuc.gr:8081

4A.2 Click "Submit New Job" → "Add New"

4A.3 Upload /home/username/etl-flink-1.0.0.jar

4A.4 After upload, click on the JAR name

4A.5 Set Program Arguments (CRITICAL - these override defaults):
     --kafka-bootstrap-servers clu02.softnet.tuc.gr:6667,clu03.softnet.tuc.gr:6667,clu04.softnet.tuc.gr:6667,clu06.softnet.tuc.gr:6667
     --config-topic etl.config.v1
     --input-topic etl.input.v1
     --output-topic etl.output.v1

4A.6 Set Parallelism: 11 (matches number of workers)

4A.7 Click "Submit"

4A.8 Monitor job at: http://clu01.softnet.tuc.gr:8081/#/job/running


OPTION B: Submit via Command Line
----------------------------------
4B.1 SSH to clu04:
     ssh username@clu04.softnet.tuc.gr

4B.2 Navigate to Flink:
     cd /usr/local/flink/

4B.3 Submit job:
     ./bin/flink run \
         -p 11 \
         -d \
         /home/username/etl-flink-1.0.0.jar

     Note: Environment variables from code defaults will be used:
     - KAFKA_BOOTSTRAP_SERVERS defaults to "kafka:9092" (WRONG for SoftNet!)

     To override, use Java -D flags (if Flink supports it):
     ./bin/flink run \
         -p 11 \
         -d \
         -yD env.java.opts="-DKAFKA_BOOTSTRAP_SERVERS=clu02.softnet.tuc.gr:6667,clu03.softnet.tuc.gr:6667,clu04.softnet.tuc.gr:6667,clu06.softnet.tuc.gr:6667" \
         /home/username/etl-flink-1.0.0.jar

================================================================================
IMPORTANT NOTES & TROUBLESHOOTING
================================================================================

FLINK VERSION COMPATIBILITY:
- Your project has been rebuilt with Flink 1.9.3 for compatibility
- SoftNet cluster has Flink 1.10.0
- Flink 1.9.3 is compatible with Java 8 (cluster runs Java 1.8.0_161)
- The JAR should work on the Flink 1.10.0 cluster (one minor version difference)
- All Kafka connector APIs have been updated to Flink 1.9.3 format


KAFKA BOOTSTRAP SERVERS:
- SoftNet uses: clu02:6667,clu03:6667,clu04:6667,clu06:6667
- Your code defaults to: kafka:9092
- MUST override via environment variables or program arguments!


ZOOKEEPER:
- SoftNet uses: clu01:2182,clu02:2182,clu03:2182
- Only needed for Kafka admin operations (topic creation)
- NOT needed for Flink job (it connects to Kafka directly)


ENVIRONMENT VARIABLES YOUR CODE USES:
- KAFKA_BOOTSTRAP_SERVERS (defaults to kafka:9092)
- CONFIG_TOPIC (defaults to etl.config.v1)
- INPUT_TOPIC (defaults to etl.input.v1)
- OUTPUT_TOPIC (defaults to etl.output.v1)


PARALLELISM:
- Your code sets parallelism to 4
- SoftNet has 33 task slots (11 workers × 3 slots each)
- Recommended parallelism: 11 (one per worker) or 33 (all slots)


COMMON ISSUES:

1. "Connection refused to kafka:9092"
   → Environment variables not set, Kafka servers hardcoded to "kafka:9092"
   → Fix: Override via program arguments or rebuild JAR with correct defaults

2. "ClassNotFoundException" or "NoSuchMethodError"
   → If this occurs, there may be a compatibility issue with Flink 1.10.0
   → Project is built with Flink 1.9.3 APIs which should be compatible

3. "Topic does not exist"
   → Kafka topics not created
   → Fix: Run STEP 3 to create topics

4. "No resources available"
   → Flink cluster full or not running
   → Fix: Check http://clu01.softnet.tuc.gr:8081 for available task slots

CLEANUP & STOP SERVICES
================================================================================

1. Stop Flink job:
   # Via Dashboard
   http://clu01.softnet.tuc.gr:8081 → Click on job → Cancel

   # Via CLI
   cd /usr/local/flink
   ./bin/flink list
   ./bin/flink cancel <JOB-ID>

2. Stop Spring Boot services:
   # Find process IDs
   ps aux | grep etl-api
   ps aux | grep etl-file-producer

   # Kill processes
   kill <PID>

3. Delete Kafka topics (if needed):
   cd /usr/hdp/current/kafka-broker
   bin/kafka-topics.sh --delete --zookeeper clu01.softnet.tuc.gr:2182 --topic etl.input.v1
   bin/kafka-topics.sh --delete --zookeeper clu01.softnet.tuc.gr:2182 --topic etl.config.v1
   bin/kafka-topics.sh --delete --zookeeper clu01.softnet.tuc.gr:2182 --topic etl.output.v1
