OVERVIEW
================================================================================

3 Components:
1. Flink Job (etl-flink-1.0.0.jar) - Processes sensor data from Kafka
2. ETL API (etl-api-1.0.0.jar) - REST API for job configurations
3. File Producer (etl-file-producer-1.0.0.jar) - Feeds Kafka with specific number of test records

Architecture:
- Flink Job: SoftNet Cluster (clu01 master, 11 workers)
- Kafka: 4 brokers (clu02, clu03, clu04, clu06 on port 6667)
- Services: Run on clu04

Versions:
- Java 8, Flink 1.9.3, Spring Boot 2.7.18, Kafka 2.4.1

STEP 4: FEED INPUT TOPIC WITH DATA
================================================================================

ssh avoutas@clu04.softnet.tuc.gr
cd /home/avoutas/boutasThesis

# Send exactly N records to Kafka input topic (producer stops automatically)
java -jar etl-file-producer-1.0.0.jar \
    --kafka.bootstrap.servers=clu02.softnet.tuc.gr:6667,clu03.softnet.tuc.gr:6667,clu04.softnet.tuc.gr:6667,clu06.softnet.tuc.gr:6667 \

    --producer.mode=random \
    --producer.max.records=10000

Expected log when finished:
✅ Random data production COMPLETED. Sent exactly 10000 records (max limit reached).
Shutting down Spring Boot application...

Generates data for:
- 6 sensor types: temperature, pressure, humidity, air_quality, light, noise
- 8 rooms: room-a, room-b, room-c, room-d, lobby, conference-room, kitchen, server-room

Common test sizes:
- Quick test: --producer.max.records=1000
- Medium test: --producer.max.records=10000
- Large test: --producer.max.records=100000
- Performance test: --producer.max.records=1000000

NOTE: For continuous data generation use --producer.max.records=-1 (must kill manually)

================================================================================
STEP 5: DEPLOY FLINK JOB
================================================================================

cd /usr/local/flink/

./bin/flink run -p 11 -d /home/avoutas/boutasThesis/etl-flink-1.0.0.jar \
    --kafka.bootstrap.servers clu02.softnet.tuc.gr:6667,clu03.softnet.tuc.gr:6667,clu04.softnet.tuc.gr:6667,clu06.softnet.tuc.gr:6667 \
    --kafka.config.topic etl.config.v1 \
    --kafka.input.topic etl.input.v1 \
    --kafka.output.topic etl.output.v1

Verify:
./bin/flink list

Expected: Job shows status "RUNNING" (NOT "RESTARTING")

PARALLELISM OPTIONS:
  -p 4   = Minimal (for testing)
  -p 11  = Baseline (1 task per worker) ✅ RECOMMENDED
  -p 22  = High load (2 tasks per worker)
  -p 33  = Maximum (3 tasks per worker, all slots)

Change parallelism: Cancel job and resubmit with different -p value
Monitor: http://clu01.softnet.tuc.gr:8081 (check backpressure, latency)

Troubleshooting:
If you get permission errors: export FLINK_LOG_DIR=~/flink-logs && mkdir -p ~/flink-logs

================================================================================
TROUBLESHOOTING
================================================================================

Job keeps restarting / Data Source shows FAILED
→ Check Flink dashboard: http://clu01.softnet.tuc.gr:8081
→ Verify command-line arguments passed correctly
→ Check TaskManager logs for Kafka connection errors

Permission denied on Flink logs
→ export FLINK_LOG_DIR=~/flink-logs && mkdir -p ~/flink-logs

API not responding
→ Check: ps aux | grep etl-api
→ Check: netstat -tuln | grep 8080

No output in Kafka
→ Check Flink job: ./bin/flink list
→ Check if data in input topic: bin/kafka-console-consumer.sh --topic etl.input.v1 --from-beginning --max-messages 5
