Κεφάλαιο: Αρχιτεκτονική και Σχεδίαση

1. Επισκόπηση Συστήματος

Το σύστημα ETL (Extract, Transform, Load) είναι μια πλατφόρμα επεξεργασίας δεδομένων σε πραγματικό χρόνο, σχεδιασμένη με αρχιτεκτονική microservices. Επεξεργάζεται ροές δεδομένων από αισθητήρες, εφαρμόζει δυναμικά διαμορφώσιμους μετασχηματισμούς, και παράγει συγκεντρωτικά αποτελέσματα.

2.2 ETL API Service

Το ETL API είναι ένα REST API βασισμένο σε Spring Boot που δέχεται configurations για ETL εργασίες.

Αρμοδιότητες:

  • Λήψη και επικύρωση configurations μέσω REST endpoint
  • Δημοσίευση configurations στο Kafka topic etl.config.v1
  • Παρακολούθηση κατάστασης εργασιών (Job Registry)

REST Endpoints:

Endpoint Method Περιγραφή
/config POST Υποβολή νέου configuration
/status/{jobId} GET Κατάσταση εργασίας
/health GET Health check
/jobs GET Λίστα όλων των εργασιών

2.3 File Producer Service

Υπηρεσία παραγωγής δεδομένων αισθητήρων με δύο modes λειτουργίας.

Modes Λειτουργίας:

Mode Περιγραφή
file Ανάγνωση δεδομένων από JSON αρχείο
random Δημιουργία ρεαλιστικών δεδομένων αισθητήρων

Τύποι Αισθητήρων:

  • temperature (Celsius)
  • pressure (hPa)
  • humidity (percent)
  • air_quality (AQI)
  • light (lux)
  • noise (dB)

Τοποθεσίες:

  • room-a, room-b, room-c, room-d
  • lobby, conference-room, kitchen, server-room

2.4 Flink Job
