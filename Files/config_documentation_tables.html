Δομή Configuration

Κάθε configuration αποτελείται από τα εξής πεδία:

Υποχρεωτικά πεδία

Πεδίο Τύπος Περιγραφή
jobId String Μοναδικό αναγνωριστικό της εργασίας ETL

Προαιρετικά πεδία

Πεδίο Τύπος Περιγραφή
transformations Array Λίστα μετασχηματισμών προς εφαρμογή

Δομή Transformation

Κάθε μετασχηματισμός στη λίστα transformations περιλαμβάνει:

Πεδίο Τύπος Υποχρεωτικό Περιγραφή
type String Ναι Τύπος μετασχηματισμού
params Object Ναι Παράμετροι του μετασχηματισμού
keyBy String Όχι Πεδίο ομαδοποίησης (για aggregations)
window String Όχι Μέγεθος παραθύρου, π.χ. "10s", "1m", "2h"

Υποστηριζόμενοι τύποι μετασχηματισμών

Element Transformations (εφαρμόζονται σε κάθε εγγραφή)

Τύπος Περιγραφή Παράμετροι
filter_greater Φιλτράρισμα τιμών > threshold sensor, field, threshold
filter_less Φιλτράρισμα τιμών < threshold sensor, field, threshold
normalize Κανονικοποίηση τιμών field, min, max
to_lowercase Μετατροπή σε πεζά field
to_uppercase Μετατροπή σε κεφαλαία field
trim_whitespace Αφαίρεση κενών field

Aggregation Transformations (εφαρμόζονται σε παράθυρο χρόνου)

Τύπος Περιγραφή Παράμετροι
sum Άθροισμα τιμών field, sensor (προαιρετικό)
max Μέγιστη τιμή field, sensor (προαιρετικό)
min Ελάχιστη τιμή field, sensor (προαιρετικό)
avg Μέσος όρος field, sensor (προαιρετικό)

3.3 Έξοδος και Αποθήκευση Αποτελεσμάτων

Μετά την εφαρμογή των μετασχηματισμών, το σύστημα παράγει αποτελέσματα τα οποία δημοσιεύονται σε πραγματικό χρόνο σε Kafka topic (etl.output.v1) για κατανάλωση από εξωτερικά συστήματα, ενώ παράλληλα αποθηκεύονται σε βάση δεδομένων MongoDB για μόνιμη αποθήκευση και ιστορική ανάλυση.

Κάθε εγγραφή εξόδου (Εικόνα 4) περιλαμβάνει τα ακόλουθα πεδία:

Πεδία Αποτελέσματος (EtlResult)

Πεδίο Τύπος Περιγραφή
jobId String Αναγνωριστικό της εργασίας που παρήγαγε το αποτέλεσμα
transformations Array Οι μετασχηματισμοί που εφαρμόστηκαν
groupingField String Το πεδίο ομαδοποίησης (π.χ. "location", "sensor")
groupingKey String Η τιμή ομαδοποίησης (π.χ. "ROOM-A")
aggregationType String Ο τύπος aggregation (sum, max, min, avg) - αν εφαρμόστηκε
field String Το πεδίο στο οποίο εφαρμόστηκε ο υπολογισμός
result Object/Number Το αποτέλεσμα επεξεργασίας
processedAt Timestamp Χρονοσήμανση ολοκλήρωσης επεξεργασίας
sensorType String Ο τύπος του αισθητήρα
measurementUnit String Η μονάδα μέτρησης
location String Η τοποθεσία προέλευσης

Τύποι Αποτελεσμάτων

Ανάλογα με τους μετασχηματισμούς που εφαρμόζονται, το σύστημα παράγει δύο κατηγορίες αποτελεσμάτων:

  • Αποτελέσματα Element Transformations: Όταν εφαρμόζονται μόνο element transformations (φίλτρα, μετατροπές κειμένου, κανονικοποίηση), το πεδίο result περιέχει την επεξεργασμένη εγγραφή του αισθητήρα.
  • Αποτελέσματα Aggregation Transformations: Όταν εφαρμόζονται aggregations, το πεδίο result περιέχει την αριθμητική τιμή που υπολογίστηκε εντός του παραθύρου χρόνου (10 δευτερόλεπτα).

Με βάση το configuration της Εικόνας 3, ένα τυπικό αποτέλεσμα εξόδου θα ήταν το ακόλουθο:

(Εικόνα 4. Παράδειγμα αποτελέσματος εξόδου)

{
  "jobId": "avgWarmRoom-job",
  "transformations": [...],
  "groupingField": "location",
  "groupingKey": "ROOM-A",
  "aggregationType": "avg",
  "field": "measurement",
  "result": 27.17,
  "processedAt": "2026-01-18T14:32:50.123Z",
  "sensorType": "temperature",
  "measurementUnit": "Celsius",
  "location": "ROOM-A"
}

Το παραπάνω αποτέλεσμα υποδεικνύει ότι ο μέσος όρος θερμοκρασίας στην τοποθεσία ROOM-A, για μετρήσεις θερμοκρασίας που ξεπερνούν τους 25°C, κατά το συγκεκριμένο παράθυρο χρόνου ήταν 27.17°C.
